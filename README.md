# Репозиторий с кодовой базой для Рейнольдс

**Репозиторий содержит**

- `CAN_protocol`: реализация протокола обмена сообщениями между платами управления
- `LPS22HB`: драйвер цифрового датчика давления
- `LowPassFilter`: реализация цифрового фильтра нижних частот с конечной импульсной характеристикой
- `PID`: реализация ПИД-контроллера
- `Projects`: проекты систем управления на основе STM32
- `Thermocouple`: драйвер термопары типа K
- `i2c_scanner`: код для сканирования устройств на шине i2c
