# Протокол бортовой коммуникации по CAN

Данный протокол реализует обмен сообщениями через периферию FDCAN контроллеров STM32.

### Использование

Формат сообщений представляет собой структуру данных `MessageData`. В данной структуре содержатся поля всех используемых на борту данных, что дает возможность легкого добавления обработки новых сообщений.

Для отправки или приема сообщения необходимо создание экземпляра структуры `MessageData`, чей адрес передается как аргумент в соответствующие функции отправки и приема. 

#### Конфигурация FDCAN

Для обмена сообщениями необходимо провести конфигурацию периферии FDCAN на *всех* контроллерах, участвующих в коммуникации. Конфигурация производится с помощью кодогенератора CubeMX и дополнительной функции `ConfigureFDCAN`. 

Типичные параметры в компании Рейнольдс приведены ниже.

| Параметр в CubeMX | Значение | Описание |
| ------------- | -------- | -------- |
| Clock Divider | Divide kernel clock by 1 ||
| Frame Format | Classic mode ||
| Mode | Normal mode | |
| Auto Retransmission | Enable | |
| Transmit Pause | Disable | |
| Protocol Exception | Enable| |
| Nominal Sync Jump Width | 1 | |
| Data Prescaler | 20 ||
| Data Sync Jump Width | 1 ||
| Data Time Seg1 | 5 ||
| Data Time Seg2 | 2 ||
| Std Filter Nbr | 5 ||
| Ext Filter Nbr | 0 ||
| Tx Fifo Queue Mode | FIFO mode ||
| Nominal Baud Rate | 1000000 bit/s | Скорость данных |

Также необходимо включить все прерывания в NVIC Settings

В функции `ConfigureFDCAN` осуществляется дополнительная настройка аппаратной фильтрации кадров. В нашем случае предлагается использовать следующие параметры.

| Параметр фильтрации | Значение | Описание |
| ------------- | -------- | -------- |
| IdType | FDCAN_STANDARD_ID ||
| FilterIndex | 0 ||
| FilterType | FDCAN_FILTER_MASK | |
| FilterConfig | FDCAN_FILTER_TO_RXFIFO0 | |
| FilterID1 | {индивидуально для устройства} | границы фильтрации |
| FilterID2 | {индивидуально для устройства} | границы фильтрации |

(*FilterIDx подбирается исходя из желаемого для обработки при приеме диапазона адресов - прим.*)


#### Прием сообщений

Прием сообщения и обработка полезных данных осуществляется в Callback-функции периферии FDCAN.
