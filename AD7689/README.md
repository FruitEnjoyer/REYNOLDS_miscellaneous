# Драйвер микросхемы АЦП AD7689

Данная директория содержит файлы для работы с микросхемой AD7689. Реализован интерфейс для считывания результатов с 8 АЦП-каналов микросхемы.

## Использование

1. Настройка периферии SPI

Для работы микросхемы проверенными параметрами модуля SPI являются:
- Full duplex mode
- NSS: software & hardware
- Motorola
- 16 Bits
- MSB first
- 5.0 MBits/s
- CPOL low
- CPHA 1 edge
- CRC calculation disabled
- NSSP mode enabled

2. Объявление экземпляра микросхемы

Перед работой необходимо инициализировать структуру для каждой микросхемы AD7689. Для корректной работы чипа **обязательно** заполнить поля `spi` и `nss_mode`. В случае, если `nss_mode` принимает значение `NSS_SOFTWARE`, также необходимо заполнить поля `nss_port` и `nss_pin` для корректной работы линии NSS (CS).

| Поле | Тип | Примечание |
| ------------- | -------- | -------- |
| spi | SPI_HandleTypeDef* | Коммуникация через этот SPI модуль |
| nss_mode | enum nss_mode | Выбор управления NSS линией |
| nss_port | GPIO_TypeDef* | Порт для линии NSS чипа |
| nss_pin | uint32_t | Пин контроллера для линии NSS |
| circular_counter | uint8_t | Счетчик выбора канала АЦП |
| txbuff | uint8_t* | Буффер для отправки конфигурации |
| rxbuff | uint8_t* | Буффер принятых данных от чипа |
| results_int | uint16_t* | Буффер результатов измерений в виде 16-битного числа |
| results_float | float* | Буффер результатов преобразований в виде вычисленных напряжений в вольтах |

Пример создания экземпляра микросхемы:
```
AD7689_t mychip = {
    .spi = &hspi1,
    .nss_mode = NSS_SOFTWARE,
    .nss_port = GPIOA,
    .nss_pin = GPIO_PIN_4
};
```

3. Инициализация

Для корректной работы микросхемы необходимо перед работой провести инициализацию. Инициализация микросхемы заключается в проверки возможности коммуникации.

Инициализация происходит вызовом функции:
```
AD7689_Init(&mychip);
```
где `mychip` - экземпляр микросхемы типа `AD7689_t`.
   
4. Считывание данных

Считывание данных может происходить посредством вызова функции `AD7689_ReadSingle()` либо функции `AD7689_ReadCircular()`. Первая функция позволяет получить измерение отдельного указанного канала, вторая же получает значение с одного из каналов, выбор которого определяется значением поля `circular_counter` в структуре микросхемы. Использование функции `AD7689_ReadCircular()` подразумевает регулярный вызов, при котором все значения с каналов АЦП будут как можно новее. Преимущество использования функции `AD7689_ReadCircular()` перед `AD7689_ReadSingle()` заключается в более быстром времени исполнения: 6-8 мкс против 25-30 мкс при использовании NSS_SOFTWARE и скорости SPI в 5 МБит/с.
