# Модуль для работы с синхорнным двигателем

Данный проект содержит реализацию абстрактного драйвера бесщёточного двигателя постоянного тока (БДПТ). Абстрактность драйвера подразумевает независимость от выбранных на целевом устройстве аппаратных ресурсов, что упрощает интеграцию при написании ПО целевого устройства.

Управление БДПТ осуществляется с применением трапецевидного управления с обратной связью по противо-ЭДС.

## Использование

1. Инициализация
   
2. Управление моментом силы
   

## Теоретическая справка

Из теории управления синфазными двигателями известно, что максимальный момент силы на ротор создается при задании в обмотках статора электрического тока, при котором его векторное представление будет перпендикулярно вектору потока магнитного поля ротора.
