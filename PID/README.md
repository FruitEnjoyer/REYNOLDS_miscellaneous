# Реализация ПИД-регулятора

### Использование

Для использования регулятора необходимо создать структуру регулятора `struct PIDController myPID`. Работа с регулятором производится через функции:
- `PID_Init`: для инициализации регулятора применяется функция инициализации, в которой устанавливаются начальные переменные регулятора.
- `PID_ReInit`: позволяет поменять ПИД-коэффициенты 
- `PID_Step`: вычисляет управляющее значение

Для работы двигателя может потребоваться создание нескольких ПИД-регуляторов:
- `struct PIDController pid_starter`: регулятор для вращения стартера
- `struct PIDController pid_pump`: регулятор для мотора топливного насоса
